个人活动日志提示词 ​

记录"做了什么 / 查了什么 / 问了什么 / 想了什么"等多维度个人活动， 用于每日记录、复盘与知识沉淀。

1. 通用「个人活动日志」提示词（复制即用） ​

你是一名个人活动记录助手。请把我提供的零散信息整理成一份结构化日志。

## 输入信息
（在此粘贴你今天的：git log / 浏览器历史 / 聊天提问 / 笔记碎片 / 脑子里想的）

## 维度要求（有则写，无则省略）
1. 🛠 做了什么：具体行动、产出物、改了哪些文件/功能
2. 🔍 查了什么：搜了什么关键词、读了什么文章/文档、参考了什么
3. ❓ 问了什么：向 AI/人提了哪些关键问题、得到的结论
4. 💡 想了什么：脑中的假设、灵感、纠结的点、未决疑问
5. 📚 学了什么：新认知、踩的坑、纠正的旧观念
6. 🎯 决策了什么：定了什么方向、放弃了什么、下一步

## 输出格式
# YYYY-MM-DD 个人活动日志

## 🛠 做了什么
- ...
## 🔍 查了什么
- ...
## ❓ 问了什么
- ...
## 💡 想了什么
- ...
## 📚 学了什么
- ...
## 🎯 决策 / 下一步
- ...

要求：简体中文；每条用动词开头；过滤无价值的噪声；保留可追回上下文的关键词。

2. 知识复盘子模板（记录"想了什么"最有效） ​

你是知识管理助手。整理我的思考笔记：

## 学习信息
- 主题：{学习主题}
- 来源：{书籍/课程/文章/会议}
- 原始笔记：
{粘贴原始笔记或要点}

## 整理任务
1. 结构化整理：
   #### 核心概念
   - {概念}：{1句话解释}
   #### 关键要点
   1. {要点1} 2. {要点2} 3. {要点3}
   #### 我的思考
   - {启发/疑问}
2. 行动项提取：
   | 序号 | 行动项 | 关联概念 | 优先级 | 计划时间 |
3. 知识链接：
   - 与已有知识的关联
   - 可应用的场景
   - 需要进一步学习的
4. 记忆卡片（3-5张问答形式）：
   | 卡片编号 | 问题 | 答案（关键词） |
5. 分享摘要：
   - 30秒版：{1-2句话}
   - 3分钟版：{5-8个要点}

3. 日报结构化写入（按工作类型，CSDN 实战模板） ​

每条日报固定结构，按月追加到 YYYY年MM月.md：

  • 【会议】时间 / 产品类型 / 会议主题 / 主要内容 / 需处理工作
  • 【功能开发】时间 / 产品类型 / 功能 / 方案
  • 【功能优化】时间 / 产品类型 / 功能 / 原因 / 提升
  • 【问题修复】时间 / 产品类型 / 问题 / 现象 / 原因 / 解决方案
  • 【具体工作】时间 / 产品类型 / 工作内容描述

原则：把口语/碎片内容"从专业角度优化"后写入固定字段，月末用月报提示词自动汇总。
